🤖 Автомод

!am
AUTOMOD
Включение/выключение автомода, просмотр статуса и настроек модулей (sym, lang, emoji, pasta).
makkkena: !am
eendychan: (𝒊) Всего фраз: 127 (+ 12 FM) • Паки (2): =toxicity(43) =spam(18)
endychann: !am sym off
eendychan: Модерация странных символов выключена
!am info
AUTOMOD
Детальная информация о настройках всех модулей автомода.
ghghh_: !am info
eendychan: (𝒊) Автомоды: sym: [ON / 10m] • emoji: [OFF / 60s] • lang: [ON / 5m] • pasta: [ON / 4 / 10m]
!bw / !mw / !dw
AUTOMOD
Добавление слов в чёрный список (бан/мут/удаление). !mw требует время: !mw 10m фраза
ghghh_: !bw "очень плохое слово" =toxicity
eendychan: Бан-слово добавлено: очень плохое слово (пак: toxicity)
makkkena: !mw 5m спам-фраза
eendychan: Мут-слово добавлено: спам-фраза (5m)
!w-
AUTOMOD
Удаление слова из любого списка (бан/мут/дел). !w- =пак — удаляет целый пак.
endychann: !w- "очень плохое слово"
eendychan: Слово удалено: очень плохое слово
!am pasta
AUTOMOD
Настройка защиты от повторяющихся сообщений: !am pasta 5 30s
makkkena: !am pasta 3 1m
eendychan: Модерация повторов: лимит 3, наказание: 1m
!am lang / emoji / sym
AUTOMOD
Управление модулями: !am lang on/off, !am emoji 300s
ghghh_: !am emoji off
eendychan: Модерация эмодзи выключена

📊 Ставки

!pred
PREDICTIONS
!pred 2m "Кто заберёт вин?" КомандаА/КомандаБ — создание ставки. !pred stop — остановить приём. !pred вариант — выбрать победителя.
makkkena: !pred 5m "Кто первый убьёт босса?" Энди/Норвил
eendychan: 📢 СТАВКА ОТКРЫТА: «Кто первый убьёт босса?» • 5 МИНУТ до окончания ставки!
ghghh_: !pred Энди
eendychan: 🎉 СТАВКА ЗАВЕРШЕНА: Победитель • «Энди»!
!pred+ / !pred-
PREDICTIONS
!pred+ "монетка" 1m "Орёл или решка?" Орёл/Решка — сохранение быстрой ставки. !pred- монетка — удаление.
endychann: !pred+ "bossfight" 3m "Кто дамагнет?" Энди/Норвил
eendychan: (★) Быстрая ставка «bossfight» сохранена: [3m] «Кто дамагнет?» • Энди/Норвил
!predinfo
PREDICTIONS
Список всех сохранённых быстрых ставок.
makkkena: !predinfo
eendychan: (★) Быстрые ставки: монетка • bossfight • 2x1
!repred / !повторить
PREDICTIONS
Повторяет последнюю созданную ставку. !repred 5m — с другим временем.
endychann: !repred 2m
eendychan: 📢 СТАВКА ОТКРЫТА: «Кто дамагнет?» • 2 МИНУТЫ до окончания ставки!
!закрыть / !удалить / !раздать
PREDICTIONS
Алиасы: !закрыть — остановить приём, !удалить — отменить ставку с возвратом баллов, !раздать вариант — выбрать победителя.
ghghh_: !удалить
eendychan: Ставка удалена - возвращаю баллы всем участникам!

🎁 Награды

!rwd+
REWARDS
!rwd+ "Випка" 100000+50000 "Описание" +vip — создание награды с автоповышением цены и выдачей VIP.
makkkena: !rwd+ "Бочка" 50000+25000 "Повышение цены" -vip
eendychan: ✓ Награда «Бочка» создана: 50 000 (+25 000) баллов | авто-VIP. Цвет: #FF4500
!rwds / !rwd
REWARDS
!rwds — список наград. !rwd "Випка" on/off/pause — включение/выключение/пауза. !rwd info "Випка" — детальная информация.
endychann: !rwds
eendychan: Награды: ✅ Випка (150 000) • ✅ Бочка (50 000) • ⏸ Таймер (10 000)
!rwd- / !rwd=
REWARDS
!rwd- "название" — удаление награды. !rwd= "Старое"="Новое" 100000 "Новое описание" — редактирование.
ghghh_: !rwd- "Бочка"
eendychan: ✓ Награда «Бочка» удалена.

⭐ Траст статус

!trust
TRUST
!trust @user — выдать доверенный статус (только модератор/стример). !trust on/off — включить систему.
endychann: !trust ghghh_
eendychan: Выдал статус для: @ghghh_
!untrust
TRUST
Забрать доверенный статус у пользователя.
makkkena: !untrust ghghh_
eendychan: Разжаловал: @ghghh_
!trusts
TRUST
Список доверенных пользователей с их статистикой мутов/банов.
ghghh_: !trusts
eendychan: Список доверенных: norvilmaster (3м/1б) • makk (12м/2б) • ghghh_ (8м/0б)
!mute / !ban
TRUST
Доверенные могут мутить и банить: !mute 10m baduser, !ban spamer. Алиасы: !мут, !уебать, !бан.
Norv1lMaster: !mute 5m reklama
eendychan: Мут reklama на 5м
!unban / !размут
TRUST
Разбан или размут пользователя доверенным.
Norv1lMaster: !unban reklama
eendychan: ✓ Разбан/размут reklama
